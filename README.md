# KACHUNK! 咣当！ (web demo)

**Play:** http://www.lelekawaii.com/kachunk-demo/

A lucky vending-machine roguelike: press one, get the whole bunch. Click any product and every
same-colour product touching it tumbles out together; bigger groups are worth quadratically more.
Toss blockers so groups merge, draft products that clump, install parts, and chain whole rows,
columns and colours into one enormous sale. Survive 8 weeks of rising quotas.

- Best on a desktop browser with a mouse (Chrome, Edge, Firefox; Safari 18.4+ for sound).
- English + 简体中文 (Settings). Progress is saved in this browser.

This repository only holds the built static site served by GitHub Pages.
